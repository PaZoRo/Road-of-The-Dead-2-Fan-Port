# Road of the Dead 2 – Godot Project

An experimental fan-made port of **Road of the Dead 2**, created with Codex and powered by the Godot Engine.

## About the Project

This project is an experimental attempt to recreate and port *Road of the Dead 2* using the Godot Engine.

Unlike the original game, this version was developed entirely with **OpenAI Codex**, using a special prompt created with help from Google Gemini. The goal was to see how far AI-assisted development could go in recreating the game.

Codex worked on the project for approximately 16 hours straight during development. However, it did not provide the original Godot project files when the initial build was completed, so I had to work around that limitation to put together this project repository.

This is an unfinished experimental project made for fun, learning, and experimentation with AI-assisted game development.

## Features

- Built with the Godot Engine.
- Developed primarily using OpenAI Codex.
- Created with assistance from a custom prompt developed with Google Gemini.
- Experimental attempt to recreate *Road of the Dead 2*.
- Source project shared publicly for anyone interested in exploring the implementation.

## Getting Started

### Requirements

- [Godot Engine](https://godotengine.org/) — use a compatible version for this project.
- A Windows PC or another system supported by Godot.

### Opening the Project

1. Download or clone this repository.
2. Extract the files if you downloaded the ZIP archive.
3. Open the Godot Engine Project Manager.
4. Click **Import** and select the project's `project.godot` file.
5. Open the project and run it from the editor.

**Note:** The project is experimental and may require additional setup or fixes before it runs correctly.

## Play the Game

The playable Windows build is available separately on itch.io.

**[Visit the itch.io page](https://pazoro.itch.io/)**

The GitHub repository contains the Godot project source files, not the standalone Windows executable.

## Project Status

The project was developed as an experiment with AI-assisted programming and game development, rather than as a polished commercial release.
